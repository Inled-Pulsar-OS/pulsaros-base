# Sistema de Archivos Overlay 📂

Cualquier archivo colocado aquí se copiará directamente a la raíz del sistema de archivos de la distro (`/`).

### Carpetas comunes:
- `etc/skel/`: Contenido por defecto para el HOME de cada nuevo usuario (configuraciones de temas, bashrc, etc.).
- `usr/share/themes/`: Temas visuales globales.
- `usr/local/bin/`: Scripts propios del sistema.
