# Configuración Global ⚙️

En esta carpeta reside la definición de "qué es" la base de nuestra distro, independientemente del escritorio.

- `base.list`: Listado de paquetes esenciales (kernel, firmware, utilidades de red).
- `sources.list`: Repositorios oficiales de Debian.
- `env.sh`: Variables de entorno comunes (versión de Debian, arquitectura por defecto).
