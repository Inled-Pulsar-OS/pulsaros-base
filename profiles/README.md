# Perfiles de Escritorio 🖼️

Aquí se define la personalidad visual y funcional de la distro. Cada subcarpeta representa un "sabor".

### Estructura de un perfil:
- `packages.list`: Paquetes específicos del entorno (ej: `gnome-shell`, `plasma-desktop`).
- `hooks/`: Scripts que se ejecutan solo si este perfil está activo.
- `overlay/`: Archivos específicos del perfil (ej: fondos de pantalla, configuraciones de dconf).
